# Milestone 3 — Small Task List

## Run
1. Extract the project folder.
2. Open `index.html` in Chrome, Edge, or Firefox.
3. Example tasks are loaded automatically on the first visit.
4. Add a task using the input and **Add task** button. Use **Delete** to remove a task.
5. Refresh the page to verify that changes persist.

The app uses browser `localStorage`; saved tasks remain in the same browser profile on the same device. Clearing site data or using another browser/device will not carry them over.

See `TEST-NOTE.md` for the required test procedure. Perform those tests yourself and update the pending results before submission.
